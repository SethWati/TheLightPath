{# _habit_card.html — one card for one habit ========================================== This little partial is rendered once per habit and gets re-used in two places: Jinja loops over it on first page render, AND the JavaScript card factory in index.html mirrors the same markup whenever the user adds a new habit via AJAX. Why two copies? Because the page is server-rendered first (matches the report's MVC story), but everything afterwards is dynamic via fetch(). The mirror in JS keeps the same shape so the user can't tell the difference between a server-rendered card and a JS-injected one. The card has, top to bottom: - habit name + delete button + category badge + SMART target - "Today's" status badge and the current streak - The risk meter (model's predicted failure %) - The 30-day sparkline (one tiny square per day) - The two big action buttons: "I did it ✨" / "× I missed today" - The small Reset and "Need advice now" buttons - The intervention card (only visible when at-risk) If you change anything in here, change the JS card factory too — keeping them in sync is the only rule. #}
